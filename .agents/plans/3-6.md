# 3.6b — ColBERT-v2 Late-Interaction Reranker

## Goal

Add ColBERT-v2 (via `ragatouille`) as an **optional alternative reranker** selectable via `RERANKER_TYPE=colbert`. The cross-encoder remains the default. ColBERT excels at large candidate sets where cross-encoder latency becomes prohibitive.

---

## Why It Matters

| Aspect | Cross-encoder (current) | ColBERT (new option) |
|---|---|---|
| **Scoring** | Full (query, doc) pair through transformer — O(M) forward passes | Token-level MaxSim — pre-encode once, score via matrix ops |
| **Latency at topM=50** | ~0.5s | ~0.3s (minimal difference) |
| **Latency at topM=200** | ~2s | ~0.5s (4× faster) |
| **Quality** | Slightly higher on short docs | Slightly higher on long docs |
| **Memory** | ~80MB model | ~400MB model |

ColBERT is the clear winner when `RERANK_TOP_M` is set high (100–200), which users might do for larger corpora.

---

## Current Reranker Wiring

```
local_llm.py init_runtime()
  → from reranker import SimpleReranker
  → reranker = SimpleReranker()

local_llm.py _retrieve_and_format()
  → reranker.rerank(query, fused_results, top_k=CONTEXT_RETRIEVAL_LIMIT)
```

**Key contract**: `reranker.rerank(query: str, documents: list, top_k: int) → list`

Both `SimpleReranker` and the new `ColBERTReranker` must satisfy this interface.

#### [NEW] [colbert_reranker.py](file:///home/lunge/Documents/repos/rag-app/python/reranker/colbert_reranker.py)

```python
"""
ColBERT-v2 late-interaction reranker via ragatouille.

Used when RERANKER_TYPE=colbert. Falls back gracefully if
ragatouille is not installed (ImportError caught at factory level).
"""

import logging

logger = logging.getLogger(__name__)


class ColBERTReranker:
    """
    Reranker using ColBERT-v2's token-level MaxSim scoring.

    Same interface as SimpleReranker: rerank(query, documents, top_k) -> list
    """

    def __init__(self, model_name="colbert-ir/colbertv2.0"):
        from ragatouille import RAGPretrainedModel

        self.model_name = model_name
        logger.info(f"Loading ColBERT reranker: {model_name}")
        self.model = RAGPretrainedModel.from_pretrained(model_name)
        logger.info("ColBERT reranker loaded successfully.")

    def rerank(self, query, documents, top_k=5):
        """
        Rerank documents using ColBERT MaxSim scoring.

        Args:
            query: Search query string
            documents: List of dicts (with 'text') or Qdrant result objects
            top_k: Number of top documents to return

        Returns:
            list: Reranked documents (same type as input)
        """
        if not documents:
            return []
        if len(documents) <= top_k:
            return documents

        try:
            # Extract texts — same logic as SimpleReranker
            texts = []
            for doc in documents:
                if hasattr(doc, 'payload') and isinstance(doc.payload, dict):
                    texts.append(doc.payload.get('text', ''))
                elif isinstance(doc, dict):
                    texts.append(doc.get('text', ''))
                else:
                    texts.append(str(doc))

            # ragatouille rerank returns list of
            # {"content": str, "score": float, "rank": int}
            results = self.model.rerank(
                query=query, documents=texts, k=min(top_k, len(texts))
            )

            # Map scored results back to original document objects
            # using text prefix matching (content may be truncated by model)
            text_to_docs = {}
            for doc, text in zip(documents, texts):
                key = text[:200]
                if key not in text_to_docs:
                    text_to_docs[key] = doc

            reranked = []
            for r in results:
                key = r["content"][:200]
                if key in text_to_docs:
                    reranked.append(text_to_docs[key])

            if not reranked:
                logger.warning("[ColBERT] Could not map results back, returning original order")
                return documents[:top_k]

            top_score = results[0]["score"] if results else 0
            bottom_score = results[-1]["score"] if results else 0
            logger.info(
                f"[ColBERT] Reranked {len(documents)} → {len(reranked)}. "
                f"Top: {top_score:.3f}, Bottom: {bottom_score:.3f}"
            )
            return reranked

        except Exception as e:
            logger.error(f"[ColBERT] Reranking failed: {e}", exc_info=True)
            return documents[:top_k]
```

### 2. Factory Function

Replace the current 2-line file with a factory:

```python
"""Reranker module — cross-encoder (default) or ColBERT late-interaction."""

import logging

from .simple_reranker import SimpleReranker

logger = logging.getLogger(__name__)

__all__ = ['SimpleReranker', 'get_reranker']


def get_reranker():
    """
    Factory: return the configured reranker instance.

    Reads RERANKER_TYPE from config:
      - 'cross_encoder' (default) → SimpleReranker
      - 'colbert' → ColBERTReranker (falls back to cross-encoder if ragatouille missing)
    """
    from config import RERANKER_TYPE

    if RERANKER_TYPE == "colbert":
        try:
            from .colbert_reranker import ColBERTReranker
            return ColBERTReranker()
        except ImportError:
            logger.warning(
                "[Reranker] ragatouille not installed, falling back to cross-encoder. "
                "Install with: pip install ragatouille"
            )
        except Exception as e:
            logger.warning(f"[Reranker] ColBERT init failed ({e}), falling back to cross-encoder")

    return SimpleReranker()
```
