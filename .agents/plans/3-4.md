# 3.4 — Adaptive-RAG Router (3-way complexity routing)

## Goal

Upgrade the query router from 2-way (`specific` | `broad`) to 3-way (`specific` | `broad` | `multi_hop`). The `multi_hop` route **auto-triggers decomposition** for that query, even when `ENABLE_DECOMPOSITION=false` globally. This gives complex queries the retrieval breadth they need without inflating cost for simple ones.

---

## Current Behavior

```
User query → LLM classifies as SPECIFIC or BROAD
→ SPECIFIC: shift weight from graph → BM25
→ BROAD:    shift weight from BM25 → graph
```

Decomposition only runs if `ENABLE_DECOMPOSITION=true` globally — all-or-nothing.

## After 3.4

```
User query → LLM classifies as SPECIFIC, BROAD, or MULTI_HOP
→ SPECIFIC:  shift weight from graph → BM25, skip community summaries
→ BROAD:     shift weight from BM25 → graph, include community summaries
→ MULTI_HOP: keep weights balanced, auto-decompose into sub-queries
```

```python
def classify(self, query: str) -> Route:
    """Return 'specific', 'broad', or 'multi_hop'. Falls back to 'broad' on failure."""
    prompt = ROUTER_PROMPT.format(query=query)
    try:
        raw = self.llm.generate_response(
            prompt=prompt, temperature=0.1, max_tokens=8
        )
    except Exception as e:
        print(f"[Agent] router LLM call failed: {e}", file=sys.stderr)
        return "broad"

    token = (raw or "").strip().upper()
    first = token.split()[0] if token.split() else ""
    first = first.strip(".,:;!?-_\"'`")

    if first.startswith("SPECIFIC"):
        return "specific"
    if first.startswith("MULTI"):
        return "multi_hop"
    if first.startswith("BROAD"):
        return "broad"

    logger.info(f"[Agent] router fallback: unparseable response {raw!r} -> broad")
    return "broad"
```

> [!NOTE]  
> `MULTI` check goes before `BROAD` so `"MULTI_HOP"` isn't accidentally matched as broad.

**Lines 57–92** — Update `adjust_weights()` to handle `multi_hop`:

```python
def adjust_weights(
    self,
    route: Route,
    vector_w: float,
    bm25_w: float,
    graph_w: float,
) -> Tuple[float, float, float]:
    """
    Shift weight_boost between paths based on route, then renormalize.

    - specific:  shift from graph -> bm25
    - broad:     shift from bm25  -> graph
    - multi_hop: keep weights unchanged (decomposition provides breadth)
    """
    v, b, g = float(vector_w), float(bm25_w), float(graph_w)

    if route == "multi_hop":
        # No weight shift — balanced retrieval, decomposition handles breadth
        return v, b, g

    shift = self.weight_boost

    if route == "specific":
        b += shift
        g -= shift
    elif route == "broad":
        g += shift
        b -= shift

    # Clamp to non-negative
    v = max(v, 0.0)
    b = max(b, 0.0)
    g = max(g, 0.0)

    total = v + b + g
    original_total = float(vector_w) + float(bm25_w) + float(graph_w)
    if total <= 0:
        return float(vector_w), float(bm25_w), float(graph_w)

    scale = original_total / total
    return v * scale, b * scale, g * scale
```
